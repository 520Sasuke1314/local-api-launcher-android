# v24：网页控制台（浏览器打开 IP:端口即得 App 同款界面）

## 用法

1. App 里点「启动服务」（局域网访问可在「功能」页打开「开放局域网 API」）。
2. 浏览器（电脑/手机都行）打开 **同一 IP:端口 的根路径**（注意：不是 `/v1`）：

   ```
   http://127.0.0.1:7891/          ← 本机
   http://192.168.x.x:7891/        ← 局域网（需先开启「开放局域网 API」）
   ```

   界面与 App 完全一致：**启动 / 功能 / 账号** 三段式底部滑块 + 暗色玻璃卡片（也支持跟随系统的浅色主题）。
3. 若服务设置了 API Key：页面顶部会提示，填入同一个 Key 即可（只存在本机浏览器 localStorage）。

App 的「启动」页也已加上 **控制台地址卡片**（一键复制）与说明。

## 能做什么

| 页 | 功能 |
|---|---|
| 启动 | 端口 + 检查占用、API Key、启动/停止服务、开放局域网、API 地址与内网穿透地址复制、关于软件（作者 Gnuning / QQ 群） |
| 功能 | 深度思考、防撤回、开发者模式、悬浮小窗、自动更换指纹（含免责说明）、内网穿透开关；Qwen 模型选择与线上模型刷新、内置浏览器通道开关与状态、Token 自动续期开关 + 提前续期分钟 + 立即续期全部 Token / 续期页面会话 |
| 账号 | DeepSeek / Qwen 双池切换、取号策略（轮询/随机）、列表显示模式、默认配额与刷新时间、配额应用全部、校验状态（Qwen 为「续期全部/校验」）、立即刷新全部配额、导入/导出、清理过期状态；单账号：启用开关、设配额、刷新配额、更换指纹、校验/续期、删除 |

> 账号**登录**（浏览器登录 / 账号密码登录）必须在 App 内完成 —— 需要 App 里的 WebView 与系统交互；控制台负责其余全部管理。

## 接口（同源，可自行脚本化）

```
GET  /                       → 控制台页面（静态，无需鉴权）
GET  /admin/api/state        → 全量状态 JSON（服务/设置/双池账号/模型/隧道/Qwen 续期概览）
POST /admin/api/action       → {action: "...", ...} → {ok, message}
```

支持的 action（部分）：`start_server` `stop_server` `toggle` `set_key` `set_qwen_model` `refresh_models`
`set_qwen_lead` `qwen_refresh_all` `qwen_refresh_page` `tunnel_start` `tunnel_stop`
`set_mode` `set_compact` `set_default_quota` `set_cooldown` `quota_to_all` `verify_all`
`reset_all_usage` `sweep` `add_account` `acc`(op=toggle|del|rotate|setquota|reset|verify)

设置了 key 时：`/v1/*` 与 `/admin/api/*` 都要 `Authorization: Bearer <key>`；`/` 静态页面本身不校验（里面没有隐私数据）。

## 实现

| 文件 | 说明 |
|---|---|
| `data/localapi/AdminWeb.kt`（新） | 单文件 HTML/CSS/JS 控制台（零依赖、无外部请求），配色直接沿用 `ui/theme/Color.kt` 的两套令牌 |
| `data/localapi/LocalApiServer.kt` | 新增 `/`（页面）、`/admin/api/state`、`/admin/api/action`；静态页免鉴权，数据/操作照常校验 key |
| `ui/LauncherScreen.kt` | 「API 地址」卡片新增**网页控制台地址**与复制按钮、说明；关于软件新增一行 |
