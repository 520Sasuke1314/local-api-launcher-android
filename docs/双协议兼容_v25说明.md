# v25：OpenAI / Anthropic 双协议兼容

客户端**二选一**，同一个本地服务同时提供两套协议（账号池、会话隔离、配额、工具协议、深度思考全部复用）：

| 协议 | base_url | 端点 |
|---|---|---|
| OpenAI 兼容 | `http://<ip>:<端口>/v1` | `POST /v1/chat/completions`、`GET /v1/models` |
| Anthropic 兼容 | `http://<ip>:<端口>` | `POST /v1/messages`、`POST /v1/messages/count_tokens`、`GET /v1/models`（返回 Anthropic 形状） |

密钥两种传法都接受：`Authorization: Bearer <key>` 或 Anthropic 风格的 `x-api-key: <key>`（未设 key 则都不需要）。

## Anthropic 兼容实现要点

- **请求**：`system`（字符串或块数组）、`messages[].content`（字符串或块数组：`text` / `image` / `tool_use` / `tool_result` / `thinking`）、
  `tools`（`{name,description,input_schema}` → 内部转成 OpenAI 形状复用现有工具协议）、
  `thinking:{type:"enabled"}`（→ 上游深度思考）、`max_tokens`、`stream`。
- **非流式响应**：`{id:"msg_..", type:"message", role:"assistant", model, content:[{type:"text",text} | {type:"tool_use",id,name,input}], stop_reason, stop_sequence, usage:{input_tokens,output_tokens}}`；
  `stop_reason` ∈ `end_turn` / `tool_use` / `max_tokens`。
- **流式响应**（标准 Anthropic SSE 事件序列）：
  ```
  message_start → ping → content_block_start(text) → content_block_delta(text_delta)…
  → [tool_use 块: content_block_start + input_json_delta + content_block_stop]
  → content_block_stop → message_delta(stop_reason, usage) → message_stop
  ```
  出错时按 Anthropic 规范发 `event: error`。
- **thinking 块只在客户端显式开启 thinking 时下发**（老版 Anthropic SDK 不认识该块类型，多发了会解析失败）；App 的「深度思考」开关只决定上游是否思考。
- **错误体**：`{"type":"error","error":{"type":"invalid_request_error|api_error","message":".."}}`，HTTP 400/401/502。
- **token 估算**：CJK 按 1 token/字、其余 4 字符/token（`count_tokens` 与 `usage` 都用它）。
- **模型路由**：沿用原逻辑 —— 名字含 `qwen*` 走 Qwen 通道、`mixed` 双池随机、其余（含 `claude-*`）走 DeepSeek 通道；响应里的 `model` 原样回显客户端请求值。

## 客户端示例

**Anthropic 风格（curl）**
```bash
curl http://127.0.0.1:7891/v1/messages \
  -H 'content-type: application/json' \
  -H 'anthropic-version: 2023-06-01' \
  -H 'x-api-key: <key>' \
  -d '{"model":"claude-3-5-sonnet-20241022","max_tokens":1024,
       "system":"你是助手","messages":[{"role":"user","content":"你好"}]}'
```

**Claude Code / Claude SDK 之类**
```bash
export ANTHROPIC_BASE_URL=http://127.0.0.1:7891
export ANTHROPIC_AUTH_TOKEN=<key>      # 未设 key 时可留空
```

**OpenAI 风格（curl）**
```bash
curl http://127.0.0.1:7891/v1/chat/completions \
  -H 'content-type: application/json' -H 'authorization: Bearer <key>' \
  -d '{"model":"deepseek-chat","stream":true,"messages":[{"role":"user","content":"你好"}]}'
```
